## Project Description: Responsive Webpage Design
**Task 2 — CODTECH Internship**
**Tools Used:** HTML & CSS

---

### Overview

For my second internship task assigned by CODTECH, I was required to design and develop a fully responsive webpage that adapts seamlessly across different screen sizes and devices. The main goal of this task was to demonstrate my understanding of responsive web design principles and to create a real, working webpage that looks good and functions properly whether it is opened on a desktop computer, a tablet, or a mobile phone. I chose to build a modern agency-style landing page called **NexaStudio** to fulfil this requirement, and I am proud to say that the final output turned out exactly the way I envisioned it.

---

### What I Built

I designed and developed a multi-section, single-page website entirely using **HTML and CSS**. The webpage contains several key sections including a navigation bar, a hero section, a services section, a portfolio section, a team section, a contact form, and a footer. Each of these sections was carefully designed to look clean, professional, and visually appealing while also being fully functional on all screen sizes.

The page has a dark modern aesthetic with a deep black background, yellow-green accent colors, and smooth layout transitions. I chose this color palette because it gives the webpage a premium and contemporary feel that is commonly seen in professional design studios and tech companies today.

---

### How I Made It Responsive

The most important part of this task was implementing responsiveness, and I achieved this entirely through **CSS**. I used **CSS Media Queries** to define different layout rules for different screen widths. I set up four breakpoints in my stylesheet to handle all major device categories.

For desktop screens wider than 900 pixels, the services section displays in a three-column grid, the team section in four columns, and the portfolio in two columns. When the screen size drops to tablet size, which is below 900 pixels, the layout automatically shifts to two columns for services and team, and the navigation links collapse and are replaced by a hamburger-style menu icon. On mobile screens below 600 pixels, everything stacks into a single column so the content remains easy to read and scroll through without any horizontal overflow. I also handled extra small screens below 380 pixels separately to make sure even very small phones display the content properly.

I also used **CSS Flexbox and CSS Grid** throughout the page to create flexible and adaptive layouts that naturally adjust based on the available screen width. These modern CSS techniques made it much easier to control the alignment, spacing, and proportional sizing of elements across different devices.

---

### Key Features of the Webpage

Some of the notable features I included in this project are a fixed navigation bar that stays at the top while scrolling, a hero section with a bold headline and call-to-action buttons, an animated scrolling marquee banner that displays the services offered, hover effects on service cards and portfolio items, a working contact form with a success message on submission, and a scroll-to-top button that appears when the user scrolls down the page.

I also added a small **device indicator tag** at the bottom-right corner of the screen that displays the current screen mode — whether it is Desktop, Tablet, Mobile, or XS Mobile. This was a practical addition that makes it very easy to visually demonstrate the responsiveness of the page during testing and presentation.

---

### What I Learned

Through this task I gained a much deeper understanding of how responsive design works in practice. I learned how to think in terms of fluid layouts rather than fixed pixel sizes, how to use media queries effectively to target different devices, and how to structure HTML in a clean and semantic way that supports good design. I also improved my skills in CSS Grid and Flexbox which are two of the most powerful tools available for modern web layout design.

Overall this project was a great learning experience and I feel much more confident in my ability to build professional, responsive webpages from scratch using just HTML and CSS.
